# Evento de migmated - Life's a Mess
## Um evento fictício na qual o artista migmated divulga o lançamento de seu mais novo álbum músical, "life's a mess".

A página principal conta com uma das músicas presentes no álbum, _"wish i could care less"_, juntamente da capa e do contador de quantos dias faltam para a música ser oficialmente lançada, abaixo está presente dois botões que abrem diferentes pop-ups, um com algumas informações a mais sobre o álbum _(gêneros músicais, artistas convidados, duração, links sociais, uma descrição, entre outros)_, enquanto o outro conta com suas informações de contato e redes sociais.

O álbum completo lança na data de 09 de outubro de 2026, ao meio dia nas plataformas Spotify e YouTube.

**!! Atenção, nenhuma informação pessoal adicionada no projeto é real para segurança de seu desenvolvedor. Esse é um projeto escolar realizado para fechamento de nota na matéria de Interfaces Web II.**
